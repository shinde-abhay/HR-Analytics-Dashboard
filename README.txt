# 📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard built using Power BI and Excel to analyze employee attrition, workforce demographics, salary, tenure, job roles, and departmental trends.

## 🚀 Dashboard Preview

[📊 **View Complete Dashboard PDF**](./hr%20analytics%20dashboard.pdf)

The PDF contains the complete 2-page dashboard.

## 📌 Key Metrics

| Metric | Value |
|---|---:|
| Total Employees | 1,470 |
| Attrition Count | 237 |
| Attrition Rate | 16.12% |
| Average Salary | 6.50K |
| Average Age | 36.92 |

## 🔍 Key Insights

- Overall employee attrition rate is **16.12%**.
- Employees who left had a lower average tenure (**5.13 years**) compared with employees who stayed (**7.37 years**).
- Attrition varies considerably across job roles and salary slabs.
- Overtime, tenure, age, department, and job role were analyzed to identify workforce attrition patterns.
